เชื่อม Firebase ก่อนใช้งาน Login จริง

เว็บเวอร์ชันนี้ใช้ Firebase Authentication จริง จึงต้องใส่ Firebase Web Config ของโปรเจกต์คุณใน firebase-config.js ก่อน

  1. สร้าง Firebase project
  2. เปิด Email/Password, Google และ Phone ใน Authentication
  3. เพิ่มโดเมน GitHub Pages ใน Authorized domains
  4. คัดลอก Web config ไปใส่ firebase-config.js
