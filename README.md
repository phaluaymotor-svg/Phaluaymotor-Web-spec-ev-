# PHALUAY MOTOR EV Showroom Website

เว็บไซต์ static สำหรับ PHALUAY MOTOR ออกแบบใหม่ให้มีโครงสร้างแบบเว็บโชว์รูมรถมืออาชีพ: Hero banner, Vehicle Finder, Inventory, Compare, Financing, Specials, EV Service, Booking/WhatsApp และ Footer

## ไฟล์หลัก
- `index.html` หน้าเว็บ
- `styles.css` ดีไซน์และ responsive
- `cars.js` ข้อมูลรถ / ราคา / สเป็ก / รูป
- `app.js` ระบบค้นหา เปรียบเทียบ ดูรายละเอียด และสร้างข้อความ WhatsApp
- `.nojekyll` สำหรับ GitHub Pages
- `amplify.yml` สำหรับ AWS Amplify

## แก้ข้อมูลรถ
เปิด `cars.js` แล้วแก้รายการใน `window.PHALUAY_CARS`
